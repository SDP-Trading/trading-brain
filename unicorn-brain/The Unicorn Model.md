# The Unicorn Model

One of the strongest algorithmic entry positions, especially after liquidity has been taken out on the opening price.

This model focuses on the Unicorn entry function, providing a clear and structured approach to applying the pattern. It's built from a set of variables — some mandatory, some optional — that together determine whether a trade is viable and how strong the setup is.
