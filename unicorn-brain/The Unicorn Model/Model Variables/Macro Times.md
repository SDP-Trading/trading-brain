# Macro Times

⬆ [[Time]]

See also: [[Manipulation]]

"A Macro is a short order of instructions for the algorithm to seek another set up to either reverse or continue."

The main macro time windows to track:

| London Session | New York AM Session | New York PM Session |
|---|---|---|
| 2:33 – 3:00 | 8:50 – 9:10 | 12:10 – 13:40 |
| 4:03 – 4:30 | 9:50 – 10:10 | 15:15 – 15:45 |
| | 10:50 – 11:10 | |

During these windows we focus on the instructions embedded in the algorithm — looking for signs of accumulation, manipulation, or expansion:
- Is price above an old high or low (indicating manipulation)?
- Is price forming a bullish breaker or bearish breaker (indicating expansion)?
- Is it consolidating (indicating accumulation)?

Grasping these instructions within the macro windows enhances our understanding of the potential next move.
