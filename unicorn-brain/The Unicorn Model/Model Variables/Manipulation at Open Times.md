# Manipulation at Open Times

⬆ [[Manipulation]]

See also: [[Time]] · [[Engineered Liquidity]] · [[Stop Hunt]]

Manipulation can happen into any PD array — for example, price could manipulate into a price imbalance like a Fair Value Gap. But for this model, what matters is that price manipulates *into taking liquidity*.

Sometimes price will manufacture liquidity on purpose, tricking traders into positioning themselves before the open, only to take that liquidity right at the open and start the distribution phase. So the main focus is spotting this piece of manipulation — liquidity being taken in/around/after the session open time.
