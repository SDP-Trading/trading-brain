# Other Types of Gaps

⬆ [[Fair Value Gaps]]

See also: [[SIBI and BISI]] · [[Fair Value Gap Anatomy]]

Besides the standard Fair Value Gap, there are other gap types that revolve around the same imbalance/rebalancing concept and can be traded the same way.

**VI — Volume Imbalance**
A gap type built on the same buy-side/sell-side inefficiency logic as a Fair Value Gap.

**Opening Gap**
A gap that forms at a session/market open, also working on the same imbalance logic.
