# Which FVG to Choose

⬆ [[Fair Value Gaps]]

See also: [[Fair Value Gap Anatomy]] · [[What is a Breaker Block]]

When there are multiple Fair Value Gaps to choose from, we need confluences to give strength to our thesis — the same way we do for any other part of the model.

We want to find confluences that support the idea of one FVG being potentially stronger than the rest. For example, between two candidate FVGs, the one sitting at a discount of the dealing range and aligned with a bullish order block is more likely to hold than the other one sitting deeper into premium with no order block support.
