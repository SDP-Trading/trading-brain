# Bullish Fair Value Gap

⬆ [[Fair Value Gaps]]

See also: [[Bearish Fair Value Gap]] · [[Bullish Breaker Block]]

A Bullish Fair Value Gap forms when price moves strongly upward. This shows aggressive buying pressure and a lack of full trading inside part of the move.

Simple sequence:
1. Sell-side liquidity is taken.
2. Price displaces higher.
3. A bullish Fair Value Gap is created.
4. Price returns into the gap.
5. We look for a potential long entry.

Simple idea: **Liquidity taken → displacement higher → bullish FVG → potential long setup**
