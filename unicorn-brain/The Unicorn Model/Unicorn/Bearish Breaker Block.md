# Bearish Breaker Block

⬆ [[What is a Breaker Block]]

See also: [[Bullish Breaker Block]] · [[Bearish Fair Value Gap]]

A Bearish Breaker Block forms when price takes buy-side liquidity and then starts moving lower.

The key candle we look for is the lowest down-closed candle before the move that takes liquidity. If there is more than one consecutive down-closed candle, we can use the full group of candles as the breaker area.

Simple sequence:
1. Price moves higher.
2. Price takes a previous high.
3. Buy-side liquidity is taken.
4. Price reacts lower.
5. The bearish breaker becomes a potential short area.

Simple idea: **Buy-side liquidity taken → bearish breaker → potential short setup**
