# FVG Entry Methods

⬆ [[Fair Value Gaps]]

See also: [[Fair Value Gap Anatomy]] · [[Where to Enter]]

When opening a position based on a Fair Value Gap, there are a few ways to place the entry:

- **IOEF / IOFED (Institutional Order Flow Entry Drill)** — on the touch of the Fair Value Gap.
- **Consequent Encroachment** — on the 50% fill of the FVG.
- **FVG Fill** — on the full fill of the FVG.
