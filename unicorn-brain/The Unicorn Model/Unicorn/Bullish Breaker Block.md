# Bullish Breaker Block

⬆ [[What is a Breaker Block]]

See also: [[Bearish Breaker Block]] · [[Bullish Fair Value Gap]]

A Bullish Breaker Block forms when price takes sell-side liquidity and then starts moving higher.

The key candle we look for is the highest up-closed candle before the move that takes liquidity. If there is more than one consecutive up-closed candle, we can use the full group of candles as the breaker area.

Simple sequence:
1. Price moves lower.
2. Price takes a previous low.
3. Sell-side liquidity is taken.
4. Price reacts higher.
5. The bullish breaker becomes a potential long area.

Simple idea: **Sell-side liquidity taken → bullish breaker → potential long setup**
