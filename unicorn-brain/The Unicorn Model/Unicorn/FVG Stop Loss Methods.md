# FVG Stop Loss Methods

⬆ [[Fair Value Gaps]]

See also: [[Fair Value Gap Anatomy]] · [[Stop Loss Placement]]

When placing a stop-loss for a position based on a Fair Value Gap, there are a few ways to do it:

- **FVG End** — near the end of the Fair Value Gap.
- **OB** — under or over an order block.
- **Swing** — under or over a swing.
