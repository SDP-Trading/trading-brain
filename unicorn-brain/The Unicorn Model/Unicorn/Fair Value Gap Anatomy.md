# Fair Value Gap Anatomy

⬆ [[Fair Value Gaps]]

See also: [[FVG Entry Methods]] · [[FVG Stop Loss Methods]]

On a Fair Value Gap, we want to check for three things:

1. **Start of the FVG** — where the FVG starts.
2. **CE — Consequent Encroachment** — the middle point of the FVG.
3. **Fill of the FVG** — the end/fill of the FVG.
