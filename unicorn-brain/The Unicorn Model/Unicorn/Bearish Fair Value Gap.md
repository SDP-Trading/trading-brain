# Bearish Fair Value Gap

⬆ [[Fair Value Gaps]]

See also: [[Bullish Fair Value Gap]] · [[Bearish Breaker Block]]

A Bearish Fair Value Gap forms when price moves strongly downward. This shows aggressive selling pressure and a lack of full trading inside part of the move.

Simple sequence:
1. Buy-side liquidity is taken.
2. Price displaces lower.
3. A bearish Fair Value Gap is created.
4. Price returns into the gap.
5. We look for a potential short entry.

Simple idea: **Liquidity taken → displacement lower → bearish FVG → potential short setup**
