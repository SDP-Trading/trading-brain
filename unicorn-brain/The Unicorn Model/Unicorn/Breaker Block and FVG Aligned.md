# Breaker Block and FVG Aligned

⬆ [[Fair Value Gaps]]

See also: [[What is a Breaker Block]] · [[How to Qualify Good Breakers]]

When it comes to the Unicorn, the FVG must be aligned with the [[What is a Breaker Block|Breaker Block]] for the setup to be considered a Unicorn. If there's no FVG aligned with the breaker, it's just a breaker — not a Unicorn.

![[Breaker FVG Aligned.png]]

Does this mean we shouldn't take a position if there's no FVG aligned? Not necessarily, but we must be aware that we won't be executing on a "Unicorn" setup — instead, we'd be relying solely on the Breaker Block to drive the price.
