# Fair Value Gap Inversion

⬆ [[Fair Value Gaps]]

See also: [[Bullish Fair Value Gap]] · [[Bearish Fair Value Gap]]

An inverted Fair Value Gap (IFVG) is a bullish or bearish FVG that gets violated — once that happens, it flips and acts as support/resistance for the move that follows.
