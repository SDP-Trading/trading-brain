# HTF to LTF Timeframe Alignment

⬆ [[High Timeframe Context]]

See also: [[Timeframe Pairing Cheat Sheet]]

There's a general rule for timeframe alignment: when a specific higher timeframe (HTF) PD array is revisited, we begin looking for positions on a corresponding lower timeframe (LTF).

| HTF PD Array | LTF to watch |
|---|---|
| Monthly | Daily |
| Weekly | 4H |
| Daily | 1H |
| 4H | 15m |
| 1H | 5m |
| 15m | 1m |

Having a Unicorn formation when both the HTF and LTF requirements are met gives the trade more weight and more confluence to consider it a higher-quality setup.
