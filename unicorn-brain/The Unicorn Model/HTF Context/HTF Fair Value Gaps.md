# HTF Fair Value Gaps

⬆ [[High Timeframe Context]]

See also: [[Fair Value Gaps]]

A higher timeframe Fair Value Gap is an imbalance left by strong price movement on a higher timeframe.

When price returns to that area, it may react because the market is revisiting an inefficient price range. This is where we can start paying attention. We do not enter just because price touches the HTF FVG — instead, once price taps into the higher timeframe FVG, we drop to a lower timeframe and look for a Unicorn.

Simple sequence:
1. Price reaches a HTF Fair Value Gap.
2. Price reacts from that area.
3. We drop to a lower timeframe.
4. We wait for liquidity to be taken.
5. We look for a Breaker Block and Fair Value Gap aligned.
6. That gives us the Unicorn entry.

Simple idea: **HTF FVG reached → LTF Unicorn → potential entry**
